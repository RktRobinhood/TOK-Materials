# Card pipeline art plan

The 72 expansion targets now have proposed public-persona mappings in [PERSONA-ROSTER.md](PERSONA-ROSTER.md) and persona-roster.json (#139). The table below retains original mechanical labels and exact asset IDs; use that ID to find the proposed pun, silhouette, signature prop, palette, source and required references. Name or animal changes never rename an asset ID implicitly. All are draft briefs, awaiting roster/familiarity and strategy review under #123 before images. Read ART-BIBLE.md and visually inspect/attach the approved style board plus a shipped creature for each released generation batch. Retain prompts, references, source PNGs, alpha/margin checks and 70px dark/light samples as in #137.

Use the existing Stage 13 list in ../../art-requests/ART-REQUESTS.md as the running production ledger. This index is generated from the creative catalogue; none of these portraits is claimed produced. Seven starter creatures are listed separately in CARD-DRAFTS.md. Total new portrait targets: 79 (7 starters + 72 expansion creatures). The seven common portraits are now generated/integrated under #137, following the refined A board milestone. See dev/starter-art.html and design/reviews/starter-art-2026-10-12.md. Future expansion portraits require ROSTER.md public-persona assignments and the approved style-board reference; then produce one tested batch at a time. Do not generate all 79 before balancing their release.

Use the game's cute/dark painted cutout style, strong outlines and readable silhouettes. Transparent idle art can serve board, hand, Collection and enlarged inspection. Preserve the existing asset build/manifest workflow; retain original generation prompts and provenance. Do not edit generated manifests by hand. Existing attack/hurt motion may transform the same cutout; add another pose only if it conveys a necessary action.

Shared presentation: code/SVG Guard backplate distinct from Shield; enlarged card text with type/rarity text and icons; five consistent rarity treatments including Mythic; cosmetic foil static overlay or one short optional sheen; shared pack illustration/opened wrapper; seven affinity symbols (six colours + generic); upcoming Fate environmental marker and inspectable node. Reuse current card backs, frames and effect sounds where suitable. Owner back selection must use saved choices with default fallback, not invented save fields. Reserve the outcome-clip area (#108) without covering board controls.

Spell/Axiom illustrations are a later shared motif set, not 138 bespoke full paintings. Start with colour/keyword motifs and only commission a unique scene for an effect needing it. Pack motion is short, skippable and Calm/reduced-motion friendly. No looping moving borders or shakes. Teacher layout review and actual viewport checks precede production release (#109).
